# Online Resume Builder

A professional, responsive resume builder built with React.

## Features

- **3 Templates**: Classic, Modern, Minimal
- **Live Preview**: Real-time updates as you type
- **Responsive Design**: Optimized for Desktop, Tablet, and Mobile
- **Animations**: Smooth transitions with Framer Motion
- **PDF Export**: One-click download using html2canvas + jsPDF
- **Auto-Save**: Data persists in localStorage
- **Collapsible Sections**: Clean editor with expandable list items

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm build
